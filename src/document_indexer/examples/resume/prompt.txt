Извлеки из резюме проекты и верни только JSON по переданной JSON Schema.

Один элемент project_experiences — один проект. В нём должно быть ровно три поля:
- project_description: значение поля «Описание проекта» или «Продукт»;
- project_position: значение поля «Должность на проекте» или «Роль на проекте»;
- project_industry: значение поля «Отрасль проекта».

Копируй только явно указанную в резюме информацию. Не классифицируй,
не нормализуй, не вычисляй и не дополняй значения своими знаниями.
Не определяй отрасль по заказчику или продукту. Не определяй грейд по должности.
Не переноси информацию между проектами.

Если конкретное поле проекта отсутствует, верни для него null.
Если проекты в резюме не выделены:
- верни ровно один элемент для кандидата;
- в project_position скопируй явно указанную общую, текущую или желаемую
  должность из заголовка, профиля или описания человека;
- не определяй должность по навыкам, обязанностям или стажу;
- project_description и project_industry заполни только при наличии явно
  указанной общей информации, иначе верни null.

Извлеки из резюме ФИО кандидата и проекты. Верни только JSON по переданной JSON Schema.

Сначала заполни candidate_name:
- это ФИО человека, о котором резюме;
- ищи в шапке, в полях «ФИО», «Фамилия», «Имя», «Отчество», в первой строке текста;
- копируй формулировку из текста, не сокращай и не переставляй слова;
- не бери название компании, должность, заказчика или имя файла;
- если ФИО в тексте нет — null.

Затем project_experiences. Один элемент — один проект. В нём ровно три поля:
- project_description: значение поля «Описание проекта» или «Продукт»;
- project_position: значение поля «Должность на проекте» или «Роль на проекте»;
- project_industry: значение поля «Отрасль проекта».

Копируй только явно указанную в резюме информацию. Не классифицируй,
не нормализуй, не вычисляй и не дополняй значения своими знаниями.
Не определяй отрасль по заказчику или продукту. Не определяй грейд по должности.
Не переноси информацию между проектами.
Верни все проекты из входного текста, не ограничивайся началом документа.

Если конкретное поле проекта отсутствует, верни для него null.
Если проекты в резюме не выделены или не найдены:
- верни ровно один элемент;
- в project_description напиши точно: Проекты не указаны;
- в project_position скопируй явно указанную общую, текущую или желаемую
  должность из заголовка, профиля или описания человека, иначе null;
- не определяй должность по навыкам, обязанностям или стажу;
- project_industry = null.

Извлеки из резюме ФИО, должность из шапки и проекты. Верни только JSON по схеме.

candidate_name:
- ФИО человека из шапки, поля «ФИО», ячейки markdown-таблицы, текста в **жирном**;
- копируй как в резюме; не бери компанию, должность, e-mail, имя файла;
- если ФИО нет — null.

candidate_position:
- общая/текущая/желаемая должность из ШАПКИ (поле «Должность»), не роль на проекте;
- не копируй офис, компанию, телефон, даты;
- если в шапке должности нет — null.

project_experiences — один элемент = один проект с полями:
- project_description: только текст поля «Описание проекта» или «Продукт»;
- project_position: только «Должность на проекте» / «Роль на проекте»;
- project_industry: только «Отрасль проекта».

Не склеивай соседние ячейки таблицы. Заказчик, город, даты, обязанности
и должность не являются описанием проекта.
project_position никогда не дата и не период («2025 – текущее время»).
project_description никогда не период работы («22.06.2016-11.06.2017»),
не одно название компании и не «город, страна».
Не классифицируй, не нормализуй, не дополняй своими знаниями.
Не определяй отрасль по заказчику. Не переноси поля между проектами.
Верни все настоящие проекты из текста.

Если поле проекта нет — null.
Если отдельных проектов нет:
- ровно один элемент;
- project_description точно: Проекты не указаны;
- project_position = candidate_position, иначе null;
- project_industry = null.

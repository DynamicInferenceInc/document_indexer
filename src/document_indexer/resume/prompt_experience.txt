В тексте резюме не удалось выделить проекты. Извлеки опыт работы по местам работы и краткий профиль кандидата.

jobs — по одному элементу на каждое место работы:
- employer — работодатель или компания;
- period — период работы так, как написано в тексте;
- position — должность;
- work_performed — чем занимался: ключевые задачи, результаты, внедрённые решения; пункты через «; »; только то, что важно для оценки опыта;
- systems — системы, продукты и технологии, с которыми работал на этом месте; через «; ».

profile — общие сведения по резюме:
- total_experience — общий стаж, если он указан в тексте;
- skills — ключевые профессиональные навыки через «; »;
- platforms — ИТ-платформы и системы (1С, SAP и другие) через «; »;
- directions — функциональные или предметные направления (финансы, логистика, казначейство и т.п.) через «; ».

Правила:
1. Копируй формулировки дословно из текста. Не перефразируй, не сокращай и не дополняй.
2. Ничего не выводи из общих знаний. Нет данных — null или пустой список.
3. Не включай контакты, адрес, дату рождения, семейное положение, образование и хобби.

Верни только JSON по схеме. Не выдумывай.
